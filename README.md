## Что это

WooCast состоит из двух частей:

| Часть | Где работает | Что делает |
|---|---|---|
| **WooCast Desktop** | Windows (Linux — в планах) | Находит приставки в сети сам или подключается по IP, захватывает экран/окно, кодирует H.264 и отправляет поток |
| **WooCast TV** | Android TV / ТВ-приставка | Принимает поток и декодирует его аппаратно, выводя на весь экран |

Никакого интернета, регистрации и телеметрии: всё общение идёт напрямую между вашими устройствами
в локальной сети по собственному протоколу [WCP/1](docs/protocol.md).

## Возможности

- 🔍 **Автообнаружение** — приставки появляются в списке сами, в течение секунды после запуска.
- ⌨️ **Ручное подключение** — ввод `192.168.1.50` или `192.168.1.50:47811`, если broadcast в сети закрыт.
- 🪟 **Экран или отдельное окно** — трансляция всего монитора либо одного приложения.
  Окно можно перетаскивать: захват следует за ним. Разрешение подбирается под размер окна.
- ⚡ **Аппаратное кодирование** — NVENC / Quick Sync / AMF с автоматическим отбором рабочего
  кодировщика и откатом на libx264.
- 🎛️ **Профили качества** — от «максимум для проводной сети» (0.32 бита на пиксель) до экономичного.
- 🩺 **Адаптивная подстройка** — если приставка не успевает декодировать, частота кадров
  снижается ступенями (60 → 30 → 15); если не успевает сеть — снижается битрейт.
  ПК различает эти два случая и сообщает, что именно изменил. Когда связь наладилась,
  параметры так же ступенями возвращаются к заданным — медленнее, чем падали, чтобы
  не начать колебаться.
- 💾 **Настройки запоминаются** — приставка, источник, окно, разрешение, качество
  и звук восстанавливаются при следующем запуске.
- 🔊 **Системный звук** — захват через WASAPI loopback (не требует «Стерео микшера»),
  AAC-LC 160 кбит/с. Приёмник ведёт счёт по звуку и выводит видео по его метке времени,
  поэтому картинка не отстаёт от звука.
- 📺 **Обратная связь с приставкой** — приёмник сообщает реальные возможности своего декодера
  и измеренную задержку; ПК показывает их и подрезает параметры под эти ограничения.
- 🎮 **Управление с геймпада** — контроллер подключается к приставке или телефону,
  а на ПК появляется виртуальный геймпад, и игра видит его как обычный. Поддерживаются
  Xbox 360 и DualShock 4. Установщик драйвера идёт в комплекте, отдельно искать не нужно.
- 🔄 **Обновления в один клик** — приложение само узнаёт о новой версии через выпуски
  на GitHub, скачивает её, сверяет контрольную сумму и перезапускается обновлённым.
  Прежняя сборка остаётся рядом: если новая не запустится, есть к чему вернуться.
- 📦 **Установщик** — один файл ставит всё сразу: приложение, ffmpeg и установщик драйвера.
  Права администратора не нужны, ярлыки создаются сами.
- 🌙 **Минималистичный интерфейс** — тёмная тема, единый стиль на ПК и телевизоре, ничего лишнего.
- 💚 **Поддержать проект** — [Boosty](https://boosty.to/andrewwoolfi): кнопка есть и на ПК, и на приставке.
- 🔓 **Apache 2.0** — код открыт, зависимости прозрачны.

## Как это работает

```
┌──────────────────────────┐                    ┌──────────────────────────┐
│   WooCast Desktop (ПК)   │                    │  WooCast TV (приставка)  │
│                          │  UDP 47810         │                          │
│  Discovery ──────────────┼─── announce ──────►│  UDP listener            │
│  Control   ──────────────┼─── JSON Lines ────►│  TCP 47811               │
│  Media     ──────────────┼─── H.264/TCP ─────►│  TCP 47812 → MediaCodec  │
│  Capture: ddagrab        │                    │  Render: SurfaceView     │
│  Encode:  NVENC/QSV/AMF  │                    │  Decode: аппаратный      │
└──────────────────────────┘                    └──────────────────────────┘
```

Подробности: [docs/protocol.md](docs/protocol.md) · [docs/architecture.md](docs/architecture.md) · [docs/roadmap.md](docs/roadmap.md)

## Проверено на практике

Сквозной тест «ПК → Android TV» (эмулятор Android TV 14, 720p30, проводная сеть):

| Показатель | Результат |
|---|---|
| Частота кадров | 30.0 к/с ровно, 1018 кадров подряд без потерь |
| Битрейт | 2.7 Мбит/с при цели 2.8 |
| Сквозная задержка | **9–31 мс** (измеряется приёмником и передаётся на ПК) |
| Круговое время | 3–7 мс |
| Очередь отправки | 0 кадров — сеть не является узким местом |
| Расхождение fps | нет накопления задержки за 40 секунд непрерывной работы |

## Быстрый старт

Если не хочется собирать самому — в `dist/` лежат готовые сборки:
`WooCast-Desktop-<версия>\WooCast.exe` (запускается как есть, .NET не нужен)
и `WooCast-TV-<версия>.apk`. Собрать их заново: `powershell -File tools\publish.ps1 -Android`.

### 1. Приставка

Соберите APK и установите на приставку (или возьмите готовый из Releases):

```powershell
cd android
.\gradlew.bat assembleDebug     # APK: android/app/build/outputs/apk/debug/app-debug.apk
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

Запустите WooCast TV — на экране появятся имя устройства, IP и порты. Они нужны,
только если автообнаружение в вашей сети не работает.

### 2. ПК

```powershell
git clone https://github.com/<ваш-аккаунт>/WooCast.git
cd WooCast

# ffmpeg нужен для захвата и кодирования
pwsh -File tools/fetch-ffmpeg.ps1

# окружение разработки: .NET, JDK, Android SDK, Gradle
. .\tools\dev-env.ps1

dotnet run --project src/WooCast.Desktop
```

В приложении: выберите приставку в списке (или введите IP) → **Транслировать**.

### Консольный вариант

Для отладки без интерфейса есть `woocast`:

```powershell
woocast probe                                   # проверить окружение и кодировщики
woocast discover                                # найти приставки
woocast windows                                 # список окон с номерами
woocast send --to 192.168.1.50 --fps 60 --quality maximum
woocast send --to 192.168.1.50 --window-id 4    # транслировать одно окно
woocast send --to 192.168.1.50 --window-id 4 --gdigrab   # принудительный откат захвата
woocast receive --dump stream.h264              # тестовый приёмник: проверить протокол без ТВ
woocast receive --simulate-fps 20               # приёмник «со слабым декодером» — проверка адаптации
woocast receive --caps 1280x720@30              # приёмник с ограниченным декодером — проверка подрезки
woocast audio                                   # проверить захват системного звука и уровень сигнала
woocast send --to 192.168.1.50 --no-audio       # трансляция без звука
```

## Готовые сборки

`tools/publish.ps1` собирает то, что можно запускать сразу:

```powershell
powershell -File tools\publish.ps1              # WooCast.exe для Windows
powershell -File tools\publish.ps1 -Android     # ещё и APK для приставки
powershell -File tools\publish.ps1 -WithFfmpeg  # автономная сборка: ffmpeg рядом с exe
```

**`WooCast.exe`** — самодостаточный: среда .NET внутри, установка не требуется.
Размер около 100 МБ, рядом кладётся `README.txt`.

**ffmpeg** по умолчанию не копируется — он весит около 160 МБ, а приложение и без него
находит установленную копию (см. `FfmpegLocator`: переменная `WOOCAST_FFMPEG`, папка
`ffmpeg` рядом с exe, кэш установщика, `PATH`). Ключ `-WithFfmpeg` делает сборку
полностью автономной.

Результат — в `dist/`: `WooCast-Desktop-<версия>/` и `WooCast-TV-<версия>.apk`.

## Требования к сборке

| Компонент | Версия | Откуда |
|---|---|---|
| .NET SDK | 10.0 | `tools/dev-env.ps1` показывает путь |
| JDK | 17 | Adoptium |
| Android SDK | platform 37, build-tools 37 | cmdline-tools |
| Gradle | 9.8 (через wrapper) | скачивается автоматически |
| AGP / Kotlin | 9.4.1 / 2.4.20 | `android/gradle/libs.versions.toml` |
| ffmpeg | 6.0+ с `ddagrab` | `tools/fetch-ffmpeg.ps1` |

> **Путь с кириллицей.** AGP отказывается собирать проект из каталога с не-ASCII символами
> (например, «Рабочий стол»). Проверка отключена в `android/gradle.properties` —
> сборка из такого пути проверена и работает.
>
> **Уборка.** `pwsh -File tools/clean.ps1 -Report` покажет, сколько занимают артефакты
> сборки, кэш NuGet и тулчейн; `-Build` (по умолчанию) удалит артефакты,
> `-Toolchain` — весь установленный тулчейн.

## Структура репозитория

```
WooCast/
├── src/
│   ├── WooCast.Protocol/     # Протокол WCP/1: discovery, control, фрейминг медиа (net10.0)
│   ├── WooCast.Capture/      # Захват и кодирование: ffmpeg, отбор кодировщиков, конвейер
│   ├── WooCast.Desktop/      # Интерфейс Avalonia (отправитель)
│   └── WooCast.Cli/          # Консольный отправитель и тестовый приёмник
├── android/
│   └── app/                  # WooCast TV: Kotlin, Compose for TV, MediaCodec
├── docs/                     # Протокол, архитектура, план развития, журнал работ
├── dist/                     # Готовые сборки: exe для Windows и APK для приставки
├── tools/                    # Скрипты окружения, сборки поставки и эмулятора
└── WooCast.slnx              # Решение .NET 10
```

отмечено и в журнале: там у каждой записи сказано, чем именно она подтверждена.
