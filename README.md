## Что это

WooCast состоит из двух частей:

| Часть | Где работает | Что делает |
|---|---|---|
| **WooCast Desktop** | Windows (Linux — в планах) | Находит приставки в сети сам или подключается по IP, захватывает экран/окно, кодирует H.264 и отправляет поток |
| **WooCast TV** | Android TV / ТВ-приставка | Принимает поток и декодирует его аппаратно, выводя на весь экран |

Никакого интернета, регистрации и телеметрии: всё общение идёт напрямую между вашими устройствами
в локальной сети по собственному протоколу [WCP/1](docs/protocol.md).

## Статус

Ход работ по задачам — в [docs/journal.md](docs/journal.md): что сделано, чем
подтверждено, что нашлось по пути и что осталось непроверенным.

| Компонент | Состояние |
|---|---|
| Протокол WCP/1 | ✅ Реализован и проверен сквозным тестом |
| WooCast Desktop (Windows) | ✅ Работает: автообнаружение, ручной IP, профили качества, телеметрия |
| WooCast TV (Android TV) | ✅ Работает: установка, запуск с пульта, аппаратное декодирование |
| Трансляция отдельного окна | ✅ Работает: захват через Windows.Graphics.Capture, автослежение за перемещением и размером |
| Захват перекрытых окон | ✅ Работает: захватывается содержимое окна, а не то, что лежит поверх него |
| Адаптивная подстройка | ✅ Работает в обе стороны: снижение при перегрузке и возврат к заданным параметрам |
| Сохранение настроек | ✅ Работает: `%APPDATA%\WooCast\settings.json` |
| Системный звук | ✅ На телевизоре и приставке. ⚠️ На телефоне пока нет: причина ищется |
| Управление с геймпада | ✅ Цепочка проверена: приёмник → сеть → виртуальный геймпад → чтение через XInput. ⏳ С живым контроллером на телефоне не проверялось |
| Обновления | ✅ Проверка версии и скачивание с проверкой контрольной суммы. ⏳ Полный цикл установки на настоящем выпуске не проверялся |
| Установщик | ✅ Собирается: один файл, без прав администратора. ⏳ Установка и удаление вживую не проверялись |
| WooCast Desktop (Linux) | 📋 Запланировано |
| Шифрование сессии | 📋 Запланировано (v1.2) |

**Осторожно с галочками.** ✅ означает, что работа проверена и подтверждена; ⏳ —
сделано, но на живом устройстве не проверено; 📋 — только запланировано. Так же
отмечено и в журнале: там у каждой записи сказано, чем именно она подтверждена.

Актуальный план — в [docs/roadmap.md](docs/roadmap.md).
