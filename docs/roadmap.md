## Этап 1 — первый рабочий стрим (Windows → Android TV) ✅

Цель достигнута: ПК находит приставку, транслирует экран, изображение появляется на телевизоре
с задержкой в десятки миллисекунд.

- [x] `WooCast.Protocol`: модели сообщений, JSON Lines, discovery, control-клиент/сервер, фрейминг
- [x] `EncoderProbe`: определение работоспособных кодировщиков и наличия `ddagrab`
- [x] `FfmpegCaptureSource`: захват полного экрана, аппаратное кодирование, `zerolatency`
- [x] `AnnexBSplitter`: разбор потока на access unit'ы по AUD
- [x] `SenderSession`: управляющая сессия + медиа-канал с ограниченной очередью
- [x] UI Avalonia: список устройств, ручной IP, настройки, телеметрия
- [x] Приёмник Android TV: discovery, control, MediaCodec-декодер, экран плеера
- [x] Тестовый приёмник на C# (`woocast receive`) — проверка протокола без приставки
- [x] Измерение сквозной задержки через синхронизацию часов (ping/pong)

**Измерено:** 30.0 к/с без потерь, 2.7 Мбит/с, задержка 9–31 мс, очередь отправки 0.

## Этап 2 — захват отдельного окна и качество 🚧

- [x] Выбор окна в интерфейсе: список окон с процессами и размерами, обновление по кнопке
- [x] Захват окна через `ddagrab` + `crop` (GPU) с откатом на область `gdigrab`
- [x] Автослежение: при перемещении или изменении размера окна захват перестраивается
- [x] Подбор разрешения под размер окна (без апскейла и лишнего битрейта)
- [x] Подстройка параметров под `announce.caps` приставки с предупреждением в интерфейсе
- [x] Адаптивное снижение частоты кадров (перегрузка декодера) и битрейта (перегрузка сети)
- [x] Возврат параметров вверх, когда связь наладилась: ступенями и осторожнее спуска,
      с увеличенной выдержкой, если подъём сразу сменяется спадом
- [x] Сохранение настроек между запусками: последняя приставка, источник, окно,
      разрешение, частота, качество, кодировщик, курсор, звук
- [x] Ручная поправка синхронизации звука (ползунок в интерфейсе и `--audio-delay`)
- [x] Готовые сборки: `tools/publish.ps1` собирает самодостаточный exe (без установки .NET)
      и APK; для автономного варианта есть ключ `-WithFfmpeg`
- [x] `Windows.Graphics.Capture`: захват содержимого окна целиком, включая перекрытые;
      кадры уходят в ffmpeg потоком, прежний способ остался запасным
      (`WOOCAST_NO_WINDOW_CAPTURE=1` отключает системный захват принудительно)
- [ ] Курсор: режимы «показывать / скрывать / подсвечивать»
- [ ] Возврат параметров вверх, когда приставка снова успевает
- [ ] Масштабирование под ТВ: целочисленное, сохранение пропорций
- [ ] Оверлей статистики на приёмнике по нажатию OK (данные уже передаются в `stats`)

## Идеи за пределами плана

- Приёмник для Windows/Linux (ПК → ПК), веб-приёмник в браузере
- Поддержка HEVC/AV1, HDR
- Трансляция без приложения на приставке: DLNA-совместимый режим для медиафайлов
- Мобильный пульт на Android/iOS для управления сессией
